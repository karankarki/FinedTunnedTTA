# Developer & Workflow Rules

## 1. No Unauthorized Git Pushes
- **NEVER** run `git push` unless the user explicitly commands you to push (e.g., "push the code").
- Do NOT automatically push changes or trigger CI/CD builds on your own.

## 2. Mandatory Prior Explanation & Approval Before Any File Edits
- **BEFORE modifying, editing, or deleting any file**, you must always tell the user first:
  1. **What** specific file(s) and lines you want to change.
  2. **Why** this change is necessary.
- Wait for the user's explicit consent/instruction before making the change.
