# Project Behavior & Workflow Rules

## 1. No Automatic / Unauthorized Git Pushes
- **NEVER** run `git push` unless the user explicitly asks you to push (e.g. "push the code").
- Do NOT push code automatically under any circumstances.

## 2. Prior Explanation & Consent Before Modifying Any Code
- **BEFORE changing any file**:
  1. Clearly state **WHAT** file and content you plan to change.
  2. Clearly explain **WHY** you want to make that change.
  3. Wait for the user to review and approve before executing the modification.
